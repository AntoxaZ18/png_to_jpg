### convertion benchmark png to jpg

Бенчмарк для оценки скорости конвертации больших png изображений через библиотеки PIL и OPENCV
с использованием многопоточности


# Использование

TARGET_SIZE = (1440, 810)  конечно разрешение
QUALITY = 75  качество jpg на выходе

Указываются внутри скрипта

# Параметры скрипта
-g - генерирует сет из 100 файлов в папке input из файла image.png (файл положить рядом со скриптом)
-i папка с PNG файлами большого разрешения
-o папка для сконвертированных jpg
-m режим конвертации "opencv" "pil"  opencv по умолчанию

Зависимости
-Pillow
-opencv 
любых версий


# Запуск скрипта

Для конвертации через opencv
```bash
python3 python3 test.py -i ./inputs -o ./jpegs -m opencv
```

C генерацией тестового сета 
```bash
python3 python3 test.py -g -i ./inputs -o ./jpegs -m opencv
```
